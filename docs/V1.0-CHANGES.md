# AJO v1.0 Changes

Repository layer and production database adapter milestone.

## Implemented
- Repository contract (`server/repository-contract.md`)
- JSON development adapter (`server/json-repository.js`)
- PostgreSQL production adapter (`server/postgres-repository.js`) with atomic `recordVote`
- Environment selection via `AJO_REPOSITORY` (`json` | `postgres`)
- Extended production schema with domain columns (`host_id`, `next_number`, `registration_open`)
- Version strings fixed to 1.0.0
- Repository-level test suite

## Unchanged AJO rules
- Dynamic player count per round
- One vote per player
- EMPTY object rejection
- Number removal + remaining-number redistribution
- Round COMPLETED only after all registered players vote
- Change Selection / Confirm Vote UX
- Real object images
- Public results

## Explicitly not claimed
- No real managed PostgreSQL instance is connected
- No cloud deployment, HTTPS, or secrets are present
- Android packaging is not part of this milestone
