# AJO v1.5.1 Changes

- Objects remain available after being selected.
- Any later player may select the same object again.
- The number currently attached to the selected object is awarded to that player.
- After every confirmed vote, the complete number set is reshuffled across all objects.
- No object becomes EMPTY during a round.
- The public popup now explains that the selected object remains available and the numbers were reshuffled.
- JSON and PostgreSQL repositories use the same rule.
- Multi-device and repository tests cover repeated selection of the same object.
