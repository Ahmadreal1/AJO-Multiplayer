# AJO v0.7 Changes

This milestone prepares the application for the real backend without pretending that a cloud service
has already been connected.

## Added
- Repository/persistence contract
- PostgreSQL production schema and transaction example
- Deterministic tests for the core voting rules
- Test command: `npm run test:rules`
- Clear separation between development JSON persistence and production database work

## Verified rules
- A player can confirm only once.
- An EMPTY object cannot be selected.
- A confirmed number is removed from the active pool.
- Remaining numbers are redistributed.
- The round becomes COMPLETED only after every registered player has voted.
- A completed round cannot accept another vote.
