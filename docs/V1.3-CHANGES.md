# AJO v1.3 Changes

Production authentication / session security and multiplayer readiness.

## Implemented
- HMAC-signed session tokens (`server/session.js`)
- Tokens issued on room create and join; stored by the client
- Reconnect recovers identity via verified token
- Host-only actions require a HOST session matching the room host
- Votes authorized only for the session player
- Separate rate limits for join and vote
- Security response headers + optional HSTS
- TRUST_PROXY / CORS_ORIGIN configuration
- Session tests (`npm run test:session`)

## Explicitly not claimed
- No live managed PostgreSQL connection
- No public HTTPS domain or certificate provisioned in this tree
- Android packaging still deferred

## Unchanged
All core AJO voting and round rules.
