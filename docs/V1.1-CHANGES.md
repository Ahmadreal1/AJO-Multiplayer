# AJO v1.1 Changes

PostgreSQL deployment readiness and live adapter verification.

## Implemented
- Schema migration script (`npm run db:migrate`)
- Live verification script (`npm run db:verify`)
  - Without DATABASE_URL → reports NOT CONNECTED (exit 0)
  - With DATABASE_URL → full contract test against the live database
- Optional local Postgres via `docker-compose.yml`
- Deployment guide: `docs/POSTGRES-DEPLOYMENT.md`
- Optional auto-migrate on boot (`AJO_AUTO_MIGRATE=1`)
- Version 1.1.0

## Unchanged
- All AJO voting rules, dynamic player counts, object system, public results
- JSON development adapter remains the default
- No secrets in source code

## Explicitly not claimed
- No real managed PostgreSQL instance is connected in this tree
- No cloud deployment, domain, or HTTPS certificate is present
